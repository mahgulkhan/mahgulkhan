## Featured Projects

### [Harf: Text Emotion Detector AI](https://github.com/mahgulkhan/HARF-Emotion-Detection-AI)
Emotion classifier for Roman Urdu / English code-switched text. It combines a TF-IDF + Logistic Regression model with a pretrained multilingual transformer, using 3 confidence-based arbitration rules to resolve disagreements. The Streamlit app handles single messages and batch WhatsApp chat analysis, with sender-wise emotion charts and CSV export.
`Python` `Streamlit` `Transformers` `scikit-learn` `Pandas` `Matplotlib`

### [Velora: Travel Recommendation Platform](https://github.com/mahgulkhan/Velora-Travel-Recommendation-System)
Full-stack platform with 3 databases (PostgreSQL, MongoDB, Neo4j), 20+ REST endpoints and 5 modular Flask blueprints. It uses the Groq API (GPT-OSS 120B) for AI itinerary planning and Leaflet.js/OpenStreetMap for route visualization.
`Python` `Flask` `PostgreSQL` `MongoDB` `Neo4j` `Groq API`

### [Diabetes Risk Prediction & Health Data Analytics](https://github.com/mahgulkhan/Diabetes-Prediction-AI)
Feedforward neural network trained on a clinical dataset, using class-weighted loss for an ~8:1 class imbalance and threshold tuning to improve risk detection. Delivered as a full-stack app with a Flask REST API, an analytics dashboard and automated email alerts for high-risk users.
`Python` `Pandas` `Matplotlib` `Flask`

### [The Campus Chronicle](https://github.com/mahgulkhan/The-Champus-Chronicle)
Mini social platform with linked lists, stacks, queues and circular arrays implemented from scratch, powering feeds, undo/redo and navigation history, plus sorting and search algorithms for trending posts and keyword discovery.
`C#` `.NET Framework` `MySQL` `WinForms` `Data Structures`
